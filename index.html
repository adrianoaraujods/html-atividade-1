Perguntas sobre HTML

1. O que significa HTML?

HTML (HyperText Markup Language) é a linguagem de marcação padrão para criação de páginas web. Ela define a estrutura e o significado do conteúdo através de elementos organizados em uma hierarquia de tags.

"HTML não é uma linguagem de programação"

2. O que é TAGS em HTML?

Tags são os blocos de construção do HTML. Cada tag representa um elemento específico, como parágrafos, títulos, imagens e formulários. Elas são escritas entre os símbolos "menor que" < e "maior que" ">", que geralmente aparecem em pares: tag de abertura e tag de fechamento.

3. Como define uma TAG no HTML?

Uma tag é definida escrevendo o nome do elemento entre "< >". A tag de abertura contém o nome do elemento, e a tag de fechamento inclui uma barra antes do nome:

<p>Este é um parágrafo em HTML.</p>
<h1>Título principal</h1>
<a href="https://exemplo.com">Link</a>

4. O que são atributos em HTML?

Atributos são propriedades adicionadas às tags para configurar ou modificar o comportamento do elemento. Eles são escritos dentro da tag de abertura, no formato nome="valor":

<img src="foto.jpg" alt="Descrição da imagem">
<a href="https://site.com" target="_blank">Clique aqui</a>
<input type="email" placeholder="Digite seu email" required>

5. Qual a estrutura básica em HTML?

Um documento HTML segue uma estrutura padronizada com declaração de doctype, metadados no cabeçalho e o conteúdo visível no corpo:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Título na aba do Navegador</title>
</head>
<body>
  <h1>Bem-vindo</h1>
  <p>Este é o conteúdo da página.</p>
</body>
</html>

6. Explique as TAGS abaixo:

Tag Descrição Função
<html> Elemento raiz Envolve todo o conteúdo da página
<head> Cabeçalho do documento Contém metadados, título e links para estilos
<meta> Metadados Define charset, viewport, descrição e keywords
<title> Título da página Aparece na aba do navegador e é usado pelo SEO
<body> Corpo do documento Exibe todo o conteúdo visível da página
<h1> Título de nível 1 Heading mais importante, representa o tema principal
<ol> Lista ordenada Cria listas numeradas com itens sequenciais
<li> Item de lista Representa cada elemento dentro de uma lista
