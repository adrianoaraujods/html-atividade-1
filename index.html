Perguntas sobre HTML

1. O que significa HTML?

HTML significa HyperText Markup Language (Linguagem de Marcação de Hipertexto). É a linguagem padrão utilizada para criar e estruturar páginas web, definindo a semântica e o conteúdo através de elementos e tags.

2. O que é TAGS em HTML?

Tags são os elementos fundamentais do HTML. Cada tag representa um tipo de conteúdo ou estrutura, como parágrafos, títulos, imagens e links. Tags geralmente vêm em pares: uma de abertura <tag> e uma de fechamento </tag>.
