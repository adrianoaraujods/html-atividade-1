Perguntas sobre HTML

1. O que significa HTML?

HTML (HyperText Markup Language) é a linguagem de marcação padrão para criação de páginas web. Ela define a estrutura e o significado do conteúdo através de elementos organizados em uma hierarquia de tags.

"HTML não é uma linguagem de programação"

2. O que é TAGS em HTML?

Tags são os blocos de construção do HTML. Cada tag representa um elemento específico, como parágrafos, títulos, imagens e formulários. Elas são escritas entre os símbolos "menor que" < e "maior que" ">", que geralmente aparecem em pares: tag de abertura e tag de fechamento.

3. Como define uma TAG no HTML?

Uma tag é definida escrevendo o nome do elemento entre "< >". A tag de abertura contém o nome do elemento, e a tag de fechamento inclui uma barra antes do nome:

<p>Este é um parágrafo em HTML.</p>
<h1>Título principal</h1>
<a href="https://exemplo.com">Link</a>

4. O que são atributos em HTML?

Atributos são propriedades adicionadas às tags para configurar ou modificar o comportamento do elemento. Eles são escritos dentro da tag de abertura, no formato nome="valor":

<img src="foto.jpg" alt="Descrição da imagem">
<a href="https://site.com" target="_blank">Clique aqui</a>
<input type="email" placeholder="Digite seu email" required>

5. Qual a estrutura básica em HTML?

Um documento HTML segue uma estrutura padronizada com declaração de doctype, metadados no cabeçalho e o conteúdo visível no corpo:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Título na aba do Navegador</title>
</head>
<body>
  <h1>Bem-vindo</h1>
  <p>Este é o conteúdo da página.</p>
</body>
</html>

6. Explique as TAGS abaixo:

Tag Descrição Função
<html> Elemento raiz Envolve todo o conteúdo da página
<head> Cabeçalho do documento Contém metadados, título e links para estilos
<meta> Metadados Define charset, viewport, descrição e keywords
<title> Título da página Aparece na aba do navegador e é usado pelo SEO
<body> Corpo do documento Exibe todo o conteúdo visível da página
<h1> Título de nível 1 Heading mais importante, representa o tema principal
<ol> Lista ordenada Cria listas numeradas com itens sequenciais
<li> Item de lista Representa cada elemento dentro de uma lista

Perguntas sobre CSS

1. O que significa CSS?

CSS (Cascading Style Sheets) é uma linguagem de estilo utilizada para definir a aparência e o layout de documentos HTML. Ela controla cores, fontes, espaçamentos, posicionamento e responsividade, separando a apresentação do conteúdo.

2. O que é SELETOR em CSS?

Um seletor é um padrão usado no CSS para selecionar e estilizar elementos HTML específicos. Ele determina a qual(is) elemento(s) as regras de estilo serão aplicadas, podendo segmentar por tag, classe, ID, atributo ou estado.

3. Como define quais são os SELETORES no CSS?

Os seletores são definidos antes do bloco de declarações, seguidos por chaves. Existem diversos tipos de seletores para diferentes níveis de especificidade:

/* Seletor por tag */
p { color: blue; }

/* Seletor por classe */
.destaque { font-weight: bold; }

/* Seletor por ID */
#cabecalho { background: black; }

/* Seletor por atributo */
input[type="email"] { border: 1px solid gray; }

4. Qual a estrutura básica em CSS?

Uma regra CSS é composta por um seletor e um bloco de declarações. Cada declaração contém uma propriedade e um valor, separados por dois pontos:

seletor {
  propriedade: valor;
  outra-propriedade: valor;
}

/* Exemplo prático */
h1 {
  font-size: 2rem;
  color: #333;
  text-align: center;
}

5. Qual a hierarquia de prioridade nos seletores em CSS?

A prioridade (especificidade) determina qual regra prevalece quando há conflitos. A hierarquia, da maior para a menor prioridade, é:

  1. !important (maior prioridade)
  2. Estilos inline (atributo style)
  3. ID (#id)
  4. Classe, atributo, pseudo-classe (.classe, [attr], :hover)
  5. Elemento, pseudo-elemento (div, ::before)
  6. Seletor universal (*), menor prioridade

6. Explique para que serve as PROPRIEDADES abaixo:

  • width / height Define a largura e altura de um elemento, respectivamente. Podem ser fixas (px) ou relativas (%, vw, vh).
  • font-size Controla o tamanho da fonte. Aceita unidades como px, rem, em e porcentagem.
  • text-decoration Adiciona decorações ao texto como underline, overline, line-through ou none.
  • text-transform Altera a capitalização do texto: uppercase, lowercase, capitalize ou none.
  • color Define a cor do texto. Aceita valores hex (#fff), rgb, hsl ou nomes de cores.
  • border Adiciona uma borda ao redor do elemento. Agrupa espessura, estilo e cor (ex: 2px solid black).
  • margin Define o espaçamento externo do elemento, criando distância entre ele e os elementos vizinhos.
  • padding Define o espaçamento interno entre o conteúdo do elemento e sua borda.
